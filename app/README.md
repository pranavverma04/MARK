# MARK app

The Next.js app for MARK. See the [project README](../README.md) for what MARK is and how it works.

```sh
npm install
npm run dev     # http://localhost:3900
./run.sh        # production build + serve on :3900
```

Copy `.env.example` to `.env.local` to enable the live copilot. Without it the copilot uses the scripted engine.
